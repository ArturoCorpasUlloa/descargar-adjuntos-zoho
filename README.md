# Descarga de adjuntos Zoho

`DescargarAdjuntosZoho.py` busca correos, descarga adjuntos PDF y permite unificarlos
para revisión. La contraseña se solicita en la interfaz y no debe guardarse en el
repositorio.

El botón **Vista demo** carga una cuenta ficticia, carpetas y métricas simuladas sin
conectarse a Zoho. Úsalo para capturas y presentaciones sin credenciales.
